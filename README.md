# Calculadora de Comisiones

Aplicación web interactiva desarrollada en React para calcular comisiones, diferencias y conversiones en múltiples monedas. Creada para optimizar tareas relacionadas con operaciones de cambio de divisas.

## Características:

- **Conversión de divisas**: Calcula tasas de compra, venta y porcentajes de ganancia en tiempo real
- **Tasas escalonadas**: Sistema de tasas diferenciadas por monto para Venezuela (VES)
- **Cálculo de comisiones**: Calcula las comisiones bancarias (Pago Móvil) de manera precisa
- **Cálculo de diferencias**: Determina el porcentaje de diferencia entre dos montos
- **Soporte multi-moneda**: Compatible con VES, COP, PEN, ARS y ESP (moneda personalizable)
- **Persistencia de datos**: Guarda automáticamente todos los valores ingresados
- **Interfaz intuitiva**: Diseño limpio y fácil de usar

## Tecnologías

- React 18.3.1
- Redux Toolkit 2.11.2 + Redux Persist 6.0
- React Router 7.0.2
- Vite 6.0.1
- ESLint 9.15

## Uso

1. Selecciona la moneda en el menú superior (VES, COP, PEN, ARS, ESP)
2. Ingresa los valores en los campos correspondientes
3. Los cálculos se actualizan automáticamente
4. En HOME puedes calcular comisiones y diferencias

# Commission Calculator

Interactive web application built in React to calculate commissions, differences, and conversions in multiple currencies. Created to optimize tasks related to foreign exchange operations.

## Features:

- **Currency conversion**: Calculates buy rates, sell rates, and profit percentages in real time
- **Tiered rates**: Tiered rate system based on amount for Venezuela (VES)
- **Commission calculation**: Accurately calculates banking commissions (Pago Móvil)
- **Difference calculation**: Determines the percentage difference between two amounts
- **Multi-currency support**: Compatible with VES, COP, PEN, ARS and ESP (customizable currency)
- **Data persistence**: Automatically saves all entered values
- **Intuitive interface**: Clean and easy to use

## Technologies

- React 18.3.1
- Redux Toolkit 2.11.2 + Redux Persist 6.0
- React Router 7.0.2
- Vite 6.0.1
- ESLint 9.15

## Usage

1. Select the currency in the top menu (VES, COP, PEN, ARS, ESP)
2. Enter the values in the corresponding fields
3. Calculations update automatically
4. In HOME you can calculate commissions and differences
